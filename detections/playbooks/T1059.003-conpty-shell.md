# T1059.003 — Windows Command Shell (ConPTY interactive shell)

**Range surface:** the `shell` command in the operator console
(ConPTY-backed interactive cmd/PowerShell, with resize and reattach).

## What the framework does

The agent creates a pseudoconsole via `CreatePseudoConsole` and spawns
the shell into it. Windows materializes the pseudoconsole as a
**headless** `conhost.exe` under the agent. Keystrokes and VT output flow
through the session transport in real time; resize (`ShellModeResize`)
and reattach (`shell <id>`) ride the same message.

## What to alert on

- **Sigma** `a1307089-bcd9-4800-982f-dd3926f1f072`
  (2026-c2-conpty-headless-conhost.yml): `conhost.exe` with the agent as
  parent, or any conhost carrying `--headless` on its command line.
- **Sigma** `90120763-6b76-4850-aedf-a6a2d57e7d28`
  (2026-c2-agent-spawns-shell.yml) also fires — the shell binary itself
  has the agent as parent regardless of the pseudoconsole host.

## Host artifacts

- Sysmon EID 1: `conhost.exe` with `--headless` args / agent parent —
  **the single most distinctive artifact of this framework's shell.**
- `cmd.exe`/`powershell.exe` children; PowerShell profile loads (EID 7)
  if the profile touches non-Microsoft modules.
- Legit consoles live under `WindowsTerminal.exe`/`explorer.exe`
  lineage; this one does not.

## False-positive profile

- Legitimate pseudoconsole consumers exist (VS Code integrated terminal,
  IDE terminals). They are signed, user-launched, and short-lived;
  correlate the parent and the agent rule.

## Validation

1. `interact <session>` → `shell` → run `systeminfo`, then `back`.
2. Expect the conpty rule + the spawns-shell rule.
3. `shells` → `shell <id>` to reattach; confirm no new process tree
   beyond the original conhost/shell pair (reattach reuses the live
   shell — a *new* conhost per attach would indicate a bug, not
   telemetry).
4. Resize the terminal, `dir`, and note that output width follows the
   operator terminal — resize itself produces no host artifact (it is a
   ConPTY resize call, invisible to Sysmon).
